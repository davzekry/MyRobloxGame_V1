# Clip Shot List (60 seconds)

Goal: an owner sees the system resist attacks within the first 10 seconds. Record at 1080p, with the Stress Test panel large and readable. No music is needed; short on-screen captions do the explaining.

Before recording: press Reset my data so you start at 250 coins with no items, and close every other panel.

| Time | Shot | On screen | Caption |
|---|---|---|---|
| 0–4 s | Stress Test panel already open | Press Run on "Give me 1,000,000 coins". The button shows Refused, and the rejection appears in the feed | "Try to cheat this shop." |
| 4–10 s | Same panel | Press Run on Buy for 0 coins, Unknown item, and Wrong type in quick succession | "Every fake request is rejected, with a reason." |
| 10–22 s | Same panel | Press Run on "Fire 50 buys at once". Hold on the PASS receipt: 250 to 0, two items bought, Gold Color refused, most requests rate limited | "50 buys at once. Charged exactly once per item." |
| 22–30 s | Close the panel, show the character | The Crate Hat and Spark Trail on the character, running so the trail shows | "Bought items appear immediately." |
| 30–40 s | Leave and rejoin (cut the loading) | Same balance, same items after rejoining | "Leave and come back: everything saved." |
| 40–52 s | Split screen: desktop and phone (use the test 9 footage) | Phone joins, desktop disconnects, phone shows the same items and balance | "Join on a second device: no lost or duplicated data." |
| 52–60 s | Title card | Game name, play link, and GitHub link | "Player data and shop systems. Built to be attacked." |

## Tips

- Use Roblox's built-in recorder or OBS. Hide the Studio window and record from the Roblox app.
- Keep each caption on screen for at least 2 seconds.
- Upload unlisted to YouTube or as a GitHub release asset, then add the link to the README.
